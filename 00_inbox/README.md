# Inbox

## 目录定位

`00_inbox/` 只放 W 的原始输入。

它回答：

- W 最初怎么描述问题。
- W 后续补充了什么原文。
- 哪些内容是未经整理的来源材料。

## 规则

- 原始输入保留原文，不改写。
- 可以复制旧 `thinks/` 内容进来，但不改变原文件语义。
- 当前事实不放这里，放 `01_context/`。
- 产品结论不放这里，放 `03_product/`。
- 技术结论不放这里，放 `04_architecture/`。
