# Archive

## 目录定位

`99_archive/` 只放历史材料、过期问题和旧输出。

它回答：

- 哪些材料已经不是当前事实。
- 哪些文档仅保留作追溯。

## 规则

- archive 不作为当前事实读取。
- 如果 archive 与 `01_context/` 冲突，以 `01_context/` 为准。
- 归档前先复制，不直接移动或删除。
- 删除旧文件必须单独确认。

## 候选归档内容

后续可归档：

- `outputs/`
- `environment/questions_for_w*.md`
- 过期的中间分析文件
