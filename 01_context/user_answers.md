# User Answers

## 原始来源

- `thinks/thnk4-回答env.md`

## 应用场景

- W 的父亲 80 岁，父母参加老年活动，包括乐器演奏和合唱。
- 父母经常需要找伴奏。
- 常见需求：
  - 找某首歌的 C 调伴奏。
  - 找某首歌伴奏，并挪到 C 调。

## 原人工流程

1. 去 YouTube 或抖音找伴奏。
2. 找下载视频网站内容的网站。
3. 下载视频。
4. 用 ffmpeg 提取音频。
5. 用微信发给父母。

## 用户与使用方式

- 希望父母可以用。
- 父母也可以推荐朋友使用。
- 父母入口可以是 App，也可以是网页快捷方式。
- 父母手机一直联网，可以访问网页和音频。

## 女儿需求

- 希望记录制作过程，给学 SC 的女儿做参考。
- 交付重点是展示人和 agent 如何协作。

## 基础设施

- 有一台美国 VM。
- 系统：Debian 12。
- 资源：1 core、1G memory、20G disk。
- 域名：`us.wumpus.top`。
- 机器上当前运行 VPN server，可能是 3x-ui。
- 端口暂时不用管，W 判断不容易冲突。
- 服务器由人来动，agent 不应直接操作。
- agent 可以提供脚本，让人采集信息或运行安装脚本。

## MVP 决策

- 视频来源先做抖音。
- 第一步要求父母提供抖音视频分享文本。
- 系统从分享文本中提取链接。
- 音频以 HTTP 链接形式提供。
- 音频保留 7 天。
- 先不做变调。
- Debian VM 可以用。
