# Context

## 目录定位

`01_context/` 只放当前有效事实。

它回答：

- 当前项目是什么。
- W 已经确认了什么。
- 当前阶段在哪里。
- 下一步是什么。

## 文件说明

| 文件 | 用途 |
|---|---|
| `current_state.md` | 当前阶段、硬规则、下一步 |
| `user_answers.md` | W 的关键回答汇总 |

## 规则

- 原始输入不放这里，放 `00_inbox/`。
- 过程记录不放这里，放 `07_traces/`。
- 过期材料不放这里，放 `99_archive/`。
- 如果旧文档和这里冲突，以这里为准。
