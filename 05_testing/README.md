# Testing

## 目录定位

`05_testing/` 只放测试策略和验证清单。

它回答：

- 什么算通过。
- 哪些层级要测。
- 失败如何判断。
- MVP 是否真的可用。

## 文件说明

| 文件 | 用途 |
|---|---|
| `test_strategy.md` | Unit / Integration / UI / E2E 测试策略 |
| `validation_checklist.md` | 当前阶段和 MVP 的验证清单 |

## 规则

- 产品范围不放这里，放 `03_product/`。
- 系统设计不放这里，放 `04_architecture/`。
- 运行说明不放这里，放 `06_delivery/`。
