# Product

## 目录定位

`03_product/` 只放产品范围、需求和路线。

它回答：

- 用户是谁。
- V1 做什么。
- V1 不做什么。
- 如何验收产品价值。

## 文件说明

| 文件 | 用途 |
|---|---|
| `mvp_v1.md` | 当前 MVP V1 范围 |
| `product_design_v1.md` | 早期父辈伴奏提取产品设计 |
| `product_design_v2.md` | 加入音频上传和结果页重构的产品草案 |

## 规则

- 技术栈不放这里，放 `04_architecture/`。
- 测试策略不放这里，放 `05_testing/`。
- agent 协作规则不放这里，放 `02_vibe/`。
