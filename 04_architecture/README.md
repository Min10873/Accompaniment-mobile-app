# Architecture

## 目录定位

`04_architecture/` 只放技术设计。

它回答：

- 用什么技术栈。
- 系统如何分层。
- 数据如何流动。
- 如何部署。

## 文件说明

| 文件 | 用途 |
|---|---|
| `tech_stack.md` | 技术栈决策 |
| `system_design.md` | 系统结构和数据流 |
| `deployment_design.md` | 部署边界和 VM 使用原则 |

## 规则

- 产品范围不放这里，放 `03_product/`。
- 测试策略不放这里，放 `05_testing/`。
- 运行手册不放这里，放 `06_delivery/`。
