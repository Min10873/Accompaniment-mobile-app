定义从文档进入编码前的开发环境边界。

本文件是创建应用工程前的闸门。

当前只允许：

- 设计开发环境。
- 明确目录结构。
- 明确本地验证方式。
- 明确哪些动作需要 W 确认。

## 本地工程建议

正式创建代码工程时，使用：

```text
app/
  backend/
    app/
    tests/
    requirements.txt
  frontend/
    index.html
    styles.css
    app.js
  docs/
```

说明：

- `backend/` 放 FastAPI 服务。
- `frontend/` 先放简单 HTML/CSS/JS。
- V1 不引入 React。
- V1 不做复杂构建链。
- V1 优先降低老人使用和部署复杂度。

## 后端环境

建议：

```text
Python 3.11+
FastAPI
uvicorn
yt-dlp 或等价下载工具
ffmpeg
pytest
```

V1 后端职责：

- 提取抖音链接。
- 创建任务。
- 下载视频。
- 调用 ffmpeg 提取音频。
- 返回 HTTP 音频链接。
- 记录任务状态。

## 前端环境

建议：

- 原生 HTML/CSS/JS。
- 手机优先布局。
- 大输入框。
- 大按钮。
- 清晰状态提示。
- 成功后显示音频链接。

暂不引入：

- React。
- 前端路由。
- 状态管理库。
- UI 组件库。

## 本地验证顺序

1. 验证 Python 可用。
2. 验证 FastAPI 服务可启动。
3. 验证抖音链接提取函数。
4. 验证 ffmpeg 可执行。
5. 验证下载工具是否能处理抖音链接。
6. 验证从视频提取音频。
7. 验证前端能提交文本并显示结果。

## 推荐第一批代码任务

创建工程后，第一批只做：

1. 抖音链接提取函数。
2. FastAPI 健康检查接口。
3. `POST /api/tasks` 的假任务返回。
4. 手机网页表单。
5. 链接提取单元测试。

先不做：

- ffmpeg 调用。
