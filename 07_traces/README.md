# Traces

## 目录定位

`07_traces/` 只放 learning trace。

它服务女儿学习需求，记录真实项目中人和 agent 如何协作。

## 子目录

| 子目录 | 用途 |
|---|---|
| `sessions/` | 一次完整协作过程 |
| `decisions/` | 重要产品或技术决策 |
| `tutorials/` | 给女儿看的整理版教程 |
| `templates/` | trace 模板 |

## 规则

- trace 不是流水账，要解释为什么。
- 记录人的判断，也记录 agent 的拆解和执行。
- 记录失败、限制和风险。
- 让学习者看到需求如何变成软件。
